# Living Torch Mod 🔥

Un mod Minecraft qui ajoute une torche vivante qui vous suit et que vous devez nourrir !

## Caractéristiques

### États de la Torche
- **Éteinte** : Immobile, pas de lumière (0% faim)
- **Faible** : Peu de mouvement, peu de lumière (1-30% faim)
- **Normal** : Mouvement normal, lumière normale (31-80% faim)
- **Excitée** : Très active, lumière brillante, attaque légère (81-100% faim)

### Nourriture
- 🪨 Charbon : +25 faim
- 🪵 Bois : +10 faim
- 🪣 Seau de lave : +50 faim

### Biomes
- **Froid** : Consomme plus de nourriture
- **Chaud/Nether** : Consomme moins
- **Humide** : Affaiblit la torche

### Mécaniques Spéciales
- Fuit l'eau et la pluie
- Vous suit automatiquement
- En état excité : attaque légère (0.5 dégâts) + met le feu
- Spawn à 10% de chance avec éclair

## Installation

1. Téléchargez Fabric Loader pour Minecraft 1.20
2. Installez Fabric API
3. Placez le mod dans le dossier `mods/`

## Utilisation

Posez une torche classique pour avoir 10% de chance de spawn une torche vivante avec éclair !
